Télécharger Eduo
  1. Installe Eduo depuis l’App Store, sur iPhone ou iPad.
  2. Reviens sur cette page et touche « Ouvrir avec ce code », ou entre le code dans Eduo : Profil › Parrainage.
  3. Fais ta première création : un quiz, un programme ou une session SOS. C’est ce qui valide l’invitation de ton ami.

Le parrainage est réservé aux nouveaux élèves (Eduo installé depuis moins de 7 jours). Chaque élève ne peut être parrainé qu’une fois.
